# Students Grades Calculator

A small Dart console program that calculates the total score and the average grade of a class.

## How it works

1. Enter the number of students
2. Enter each student's grade
3. The program prints the **total score** and the **average**

## Concepts practiced

- Reading user input with `dart:io`
- `for` loops
- Variables and arithmetic operations

## Run

```bash
dart run my_proj.dart
```
